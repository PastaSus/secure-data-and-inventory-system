- **Open fork, must be answered before drafting:** the project name describes a *system*, not a game. Is the deliverable (a) a reusable Luau library/framework for other experiences, or (b) the data + inventory backend of a standalone Roblox experience? This decides genre, audience, comparables, and whether `gds-gdd` even applies.
- **User delegated all discovery answers.** In response to the 5-question discovery batch, the user replied "im leaving stuff to you remember?" — confirming standing instruction: the agent decides, tags inferences `[ASSUMPTION]`, the user reviews. No interview answers were collected; all content below is agent-inferred and flagged as such in the brief.
- **Decision: deliverable = both, game first.** Standalone Roblox experience is primary; the secure data + inventory system is written as a self-contained server-only module from day one so it stays extractable. Rationale (see `addendum.md` §1): a security claim is unprovable without live players, a library with no flagship has no adoption story, and the GDS workflow assumes a game to design.
- **Decision: working title "Curio Vault."** A collect-a-thon (dive → find → stow → complete sets) at a ruined seaside observatory. Chosen because the genre makes inventory *the* gameplay — which lets the system's integrity be a visible, felt feature rather than invisible plumbing — and because the loop is proven at massive scale (see addendum §3) while being reachable solo.
- **Decision: genre/pillars** — cozy collect-a-thon with light trading; pillars = Integrity is gameplay, Find→Stow→Complete, Trade safely, Vault is the trophy.
- **Decision: audience** — primary 9–16 collection-game players, mobile-first; secondary 13–20 traders/collectors. Not "everyone."
- **Decision: persistence = ProfileStore**, session locking non-negotiable (ProfileService archived; DataStore2 lacks session locking; Knit archived and not persistence). Networking layer deferred to `gds-game-architecture`.
- **Decision: MVP boundary** — 1 biome, ~40 items / 4 rarities / 3 sets, persistent vault, ProfileStore save, one dupe-proof trade path, pack capacity. **Explicitly out:** monetization, combat, daily chores, cosmetics shop, guilds, leaderboards.
- **Decision: timeline assumption** — solo part-time, ~6 weeks to MVP; personal/portfolio project, no budget line.
- **Trade path flagged as the #1 technical risk** — must be prototyped before a second trade feature is designed.
